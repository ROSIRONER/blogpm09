# Blog (PHP/MySQL)

## Запуск
1. Создайте БД `blog` и примените `schema.sql`.
2. При необходимости задайте переменные окружения: `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`.
3. Запустите сервер:
   ```bash
   php -S 0.0.0.0:8080
   ```
4. Откройте `http://localhost:8080/index.php`.

## Возможности
- Регистрация/авторизация/выход.
- Главная с пагинацией по 5 постов.
- Страница поста, AJAX-комментарии, кнопки лайков (JS).
- Админ-панель для CRUD постов и модерации комментариев.
