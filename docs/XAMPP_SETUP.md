# Инструкция запуска на XAMPP (Windows/macOS)

## 1) Подготовка
1. Установите XAMPP.
2. Скопируйте проект в папку `htdocs`, например:
   - `C:\xampp\htdocs\blogpm09` (Windows)
   - `/Applications/XAMPP/htdocs/blogpm09` (macOS)

## 2) Запуск сервисов
1. Откройте **XAMPP Control Panel**.
2. Запустите:
   - **Apache**
   - **MySQL**

## 3) Создание БД
1. Откройте `http://localhost/phpmyadmin`.
2. Создайте БД `blog` с кодировкой `utf8mb4`.
3. Импортируйте `schema.sql` (вкладка **Import**).

## 4) Подключение проекта к БД
Проект по умолчанию использует:
- host: `127.0.0.1`
- db: `blog`
- user: `root`
- password: пусто

Если у вас другие параметры, передайте их как переменные окружения Apache/PHP,
либо временно поменяйте значения в `config/db.php`.

## 5) Открытие проекта
Откройте в браузере:
```text
http://localhost/blogpm09/index.php
```

## 6) Создание администратора
После регистрации обычного пользователя назначьте роль `admin` вручную в phpMyAdmin:
```sql
UPDATE users SET role='admin' WHERE email='ваш_email@example.com';
```

## 7) Проверка
- Регистрация/вход работают.
- Посты видны карточками на главной.
- На телефоне меню раскрывается кнопкой.
- В админке доступны CRUD-постов и модерация комментариев.
