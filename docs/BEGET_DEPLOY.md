# Инструкция деплоя на Beget

## 1) Подготовьте архив
1. На локальной машине упакуйте проект в zip (без `.git`).
2. Убедитесь, что в архиве есть `schema.sql` и папка `uploads/`.

## 2) Создайте сайт и БД в Beget
1. В панели Beget создайте сайт (домен/поддомен).
2. Создайте MySQL базу данных.
3. Запомните параметры:
   - `DB_HOST`
   - `DB_NAME`
   - `DB_USER`
   - `DB_PASS`

## 3) Загрузка файлов
1. Через файловый менеджер Beget или FTP загрузите проект в корень сайта (`public_html` или `www`).
2. Проверьте права на папку `uploads/` (должна быть доступна на запись веб-серверу).

## 4) Импорт SQL
### Вариант A (phpMyAdmin в Beget)
1. Откройте phpMyAdmin в панели Beget.
2. Выберите созданную БД.
3. Импортируйте `schema.sql`.

### Вариант B (SSH, если доступно)
```bash
mysql -h <host> -u <user> -p <db_name> < schema.sql
```

## 5) Настройка подключения к БД
Укажите реальные параметры БД в окружении PHP/хостинга.
Если переменные окружения недоступны, задайте их напрямую в `config/db.php`.

## 6) Проверка после деплоя
1. Откройте `https://ваш-домен/index.php`.
2. Зарегистрируйте пользователя.
3. Назначьте роль `admin` через phpMyAdmin:
```sql
UPDATE users SET role='admin' WHERE email='admin@example.com';
```
4. Проверьте:
   - создание поста с изображением,
   - комментарии,
   - адаптивность на мобильном.

## 7) Рекомендуемо для продакшена
- Отключить отображение ошибок PHP в браузере.
- Включить HTTPS (SSL сертификат).
- Делать бэкапы базы данных.
- Ограничить права доступа к служебным файлам.
